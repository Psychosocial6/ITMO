## Задание

Согласно варианту, необходимо реализовать определенный тип коллекции, хранящий определенный тип данных (по варианту) на языке **C**.

Коллекция поддерживает некоторый набор действий (вставка, удаление и прочее), зависящий от варианта задания.

**Требования к структуре проекта:**
Проект должен содержать следующие модули:
* `collection`
* `domain`
* `ui`
* `main`

> Для всех файлов, кроме `main`, требуется наличие заголовочного файла (`.h`).

### Сборка из командной строки


1.  **Клонируйте репозиторий:**
    ```bash
    git clone [URL]
    cd ProgrammingLanguagesLab1 
    ```

2.  **Создайте директорию для сборки и сконфигурируйте проект:**
    ```bash
    cmake -B build
    ```

3.  **Соберите проект:**
    ```bash
    cmake --build build
    ```

4.  **Запустите приложение:**

    *   **На Windows (в PowerShell или CMD):**
        ```powershell
        .\build\ProgrammingLanguagesLab1.exe
        ```
    *   **На Linux или macOS:**
        ```bash
        ./build/ProgrammingLanguagesLab1
        ```
