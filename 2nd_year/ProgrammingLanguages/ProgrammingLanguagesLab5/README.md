
# Программа для вычисления значения арифметического выражения в целых числах

Программа получает ввод через поток стандартного ввода и выводит результаты работы в поток стандартного вывода.

* **expr** — задать выражение — разбирает текст выражения и осуществляет необходимую кодогенерацию для вычисления выражения как функции.
* **set** — задать значение переменной — ассоциирует целочисленное значение с именем переменной.
* **do** — вычислить выражение — вызывает сгенерированную для выражения функцию и передаёт ей необходимые значения переменных, выводит значения всех вычисленных подвыражений в составе выражения и его итоговое значение.
* **exit** — выйти из программы — завершает работу.

Для реализации используются **Reflection.Emit** для кодогенерации и алгоритм **Shunting Yard** для парсинга выражения. Все вычисления производятся в целых 64-битных числах.
