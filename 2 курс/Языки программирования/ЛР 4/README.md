Приложение на Python, использующее библиотеку на C# для построения визуализации фрактала Коллатца.



## Установка



```bash

git clone https://gitlab.se.ifmo.ru/Psychosocial/programminglanguageslab4.git

cd ProgrammingLanguagesLab4

```



## Запуск



```bash

python main.py

```



Ознакомиться с кодом библиотеки можно в директории `CollatzLib`.



## Сборка библиотеки



```bash

cd CollatzLib

dotnet publish -c Release -r win-x64

```
