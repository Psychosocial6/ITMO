# Bidirectional Pipe

Программа, реализующая двусторонний канал передачи данных с использованием разделяемой памяти и потоков на языке C#. При запуске двух экземпляров программы они объединяются в пару, каждый экземпляр передает другому ввод из своего терминала, а также принимает ввод из терминала второго экземпляра. Количество пар процессов, образующих канал задается переменной `MAX_PAIRS`, размер буфера для сообщений - `BUFFER_SIZE`.

## Сборка и запуск

### Клонирование репозитория:
```bash
git clone https://gitlab.se.ifmo.ru/Psychosocial/ProgLangLab3.git
cd ProgLangLab3
```

### Сборка:
```bash
dotnet build
```

### Запуск: 
```bash
dotnet run
```
Для взаимодействия необходимо создать еще хотя бы один экземпляр программы, выполнив команду `dotnet run` в той же директории, в другом терминале.
